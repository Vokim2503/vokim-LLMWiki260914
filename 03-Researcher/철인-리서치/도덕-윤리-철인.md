## 1. 소크라테스 (BC 470~399) — 덕은 지식

| 항목 | 내용 |
|---|---|
| 핵심 주장 | **덕은 지식이다.** 아무도 악을 **원해서** 행하지 않는다. 악행은 무지에서 나온다. |
| 파생 명제 | 지식이 있으면 덕을 행할 수밖에 없다 → 덕을 가르칠 수 있다 |
| 실천 방법 | **산파술(문답)** — 스스로의 무지를 깨닫게 하는 대화. "너 자신을 알라" |
| 핵심 문장 | "유일한 선은 지식이고, 유일한 악은 무지다." — **원문 대조 필요** (2차 자료: Reddit QuotesPorn) |
| 출처 | 위키백과 「소크라테스」 / 철학 강좌(유튜브) — "덕은 지식이다. 모든 덕은 하나이다" |

**발췌 메모:** 소크라테스는 도덕을 "배우는 것"으로 만들었습니다. 악한 사람이 아니라 **무지한 사람**이 악을 저지른다는 관점은 이후 모든 덕 윤리의 출발점입니다.

## 2. 플라톤 (BC 427~347) — 정의와 4원덕

| 항목 | 내용 |
|---|---|
| 핵심 주장 | 덕은 이데아를 아는 데서 온다. **정의(디카이오쉬네)** 가 최고 덕. |
| 4원덕 | **지혜 · 용기 · 절제 · 정의** — 영혼의 삼분(이성·의지·욕망)과 대응 |
| 국가론 | 개인의 정의 = 영혼의 질서 / 국가의 정의 = 계급의 조화 (철인왕) |

| 출처 | 위키백과 「플라톤」·「동굴의 비유」 |

**발췌 메모:** 플라톤은 도덕을 "영혼의 건강"으로 보았습니다. 정의로운 사람은 욕망이 이성의 지배를 받는 사람입니다.

## 3. 아리스토텔레스 (BC 384~322) — 중용과 행복

| 항목 | 내용 |
|---|---|
| 핵심 주장 | 최고선은 **행복(에우다이모니아)** 이고, 행복은 덕 있는 활동에서 온다. |
| 덕의 정의 | 덕은 두 악덕(과잉·결핍) 사이의 **중용(메소테스)** |
| 예시 | 용기 = 무모함(과잉)과 겁쟁이(결핍)의 중간. 절제·관대함도 같은 구조 |
| 실천 방법 | 습관 — "우리는 옳게 행동함으로써 올바른 사람이 된다" (개념) |
| 저작 | 《니코마코스 윤리학》 10권 (아들 니코마코스가 편집) |
| 출처 | 한국경제 생글생글 「니코마코스 윤리학」 기사 / 위키백과 「아리스토텔레스」 |

**발췌 메모:** 아리스토텔레스는 덕을 "태도"가 아니라 "습관·활동"으로 보았습니다. 도덕을 실천의 문제로 만든 사람입니다.

## 4. 에피쿠로스 (BC 341~270) — 평정의 윤리

| 항목 | 내용 |
|---|---|

| 구분 | 자연적·필요한 욕구(먹기) ↔ 헛된 욕구(명예·권력) — 헛된 욕구를 버릴 때 평정이 온다 |

**발췌 메모:** "쾌락주의"라는 오해와 달리, 에피쿠로스는 과식·방탕이 아니라 **소박한 기쁨**을 말합니다. 욕망의 정학(欲望의 靜學)입니다.

## 5. 스토아 학파 — 덕이 유일한 선 (제논 · 세네카 · 에픽테토스 · 마르쿠스 아우렐리우스)

| 항목 | 내용 |
|---|---|
| 핵심 주장 | **덕만이 유일한 선** 이고, 건강·부·명예는 "선호되는 것"에 불과하다. |
| 자연에 따르는 삶 | 자연(=이성=자연법)에 따르는 삶이 곧 덕 있는 삶 — 나무위키 「스토아 학파」 |
| 에픽테토스 | **"내 것과 내 것이 아닌 것"** — 통제할 수 있는 것(판단·의지)에만 집중 |
| 아우렐리우스 | 《명상록》 — 자기 대화로 마음을 다스림. 황제가 쓴 자기 훈육서 |
| 세네카 | 《인생의 짧음에 관하여》 — 시간의 사용이 곧 도덕의 문제 |
| 출처 | 위키백과 각 인물 / 나무위키 「스토아 학파」(2차 자료) |

**발췌 메모:** 스토아는 도덕을 "내가 통제하는 영역"으로 한정했습니다. 타인·운명은 내 것이 아니므로 분노할 이유가 없다는 실천 윤리입니다.

## 7. 토마스 아퀴나스 (1225~1274) — 자연법

| 항목 | 내용 |
|---|---|

## 8. 칸트 (1724~1804) — 정언명령

| 항목 | 내용 |
|---|---|
| 핵심 주장 | 도덕은 결과가 아니라 **의지의 준칙** 이 문제다. 오직 의무에서 행한 행위만 도덕적이다. |
| 정언명령 (제1공식) | "네 의지의 준칙이 항상 주관적인 동시에 보편적인 법칙 수립이라는 원리로서 타당하도록 행위하라" — **출처:** 네이버 블로그 칸트 정언명령 해설 (원문 대조 필요) |
| 제2공식 | 인간을 언제나 목적으로 대하고, 수단으로만 대하지 말라 (개념) |
| 구분 | 완전의무(거짓 약속 금지) ↔ 불완전의무(자신 계발) — 나무위키 「정언 명령」 |
| 실천 방법 | "네가 원하는 준칙이 모든 사람의 법칙이 될 수 있나?"를 스스로 묻기 |
| 출처 | 위키백과 「이마누엘 칸트」·「정언 명령」 |

**발췌 메모:** 칸트는 도덕을 "마음의 자세"로 옮겼습니다. 같은 행동이라도 동기가 다르면 도덕성이 달라집니다.

## 11. 니체 (1844~1900) — 도덕의 계보

| 항목 | 내용 |
|---|---|
| 핵심 주장 | 도덕도 **가치 평가의 산물** 이다. 기존 도덕의 기원을 추적(계보학)해 재평가한다. |
| 주인도덕 vs 노예도덕 | 주인도덕 = 강함·창조의 가치 / 노예도덕 = 약자의 원한에서 나온 가치 (선/악 구분) — 네이버 블로그 「도덕의 계보학」 해설 (2차 자료) |
| 실천 방법 | **가치의 전도** — 스스로 가치를 창조하는 초인(Übermensch) |
| 핵심 문장 | "신은 죽었다" — *개념 요약 (출처 대조 필요)* |
| 출처 | 위키백과 「프리드리히 니체」·「도덕의 계보학」 |

**발췌 메모:** 니체는 도덕 자체를 의심의 대상으로 만들었습니다. "이 도덕은 누구에게 유리한가?"라는 질문은 도덕 글쓰기에 긴장을 줍니다.
