# 철인 리서치 — 개요

> **목적:** 고대에서 근대에 이르는 철인(哲人)을 리스트 업하고, 각 철인의 특성을 분류하여 앞으로의 글쓰기에 참조할 기반을 만듭니다.
> **근거 지침:** 볼트 루트 `Skill.md` (사용자 작성) → [[볼트-운영-지침]]
> **출처:** 한국어 위키백과 (고대 그리스 철학·중세 철학·근대 철학 문서) 및 각 인물 표제어. 검증 범위는 문서별로 명시했습니다.


## 3단계 진행 상태

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 철인 리스트 업 + 특성 분류 | ✅ 완료 |
| 2 | 철인별 봇 생성 (각 봇에 특성 이입) | ⏸ 대기 (사용자 지시 대기) |
| 3 | 봇에서 글귀·명언 준비 후 대기 | ⏸ 대기 |

## 분류 축 (특성 분류 기준)

1. **시대** — 고대 / 중세 / 근대
2. **문제 영역** — 존재론 · 인식론 · 윤리학 · 정치철학 · 신학
3. **사유 방식** — 이성(합리) / 경험 / 직관 / 신앙 / 실천
4. **핵심 개념** — 각 철인을 하나의 대표 개념으로 압축
5. **계보** — 누구에게서 이어받아 누구에게 전달했는가
