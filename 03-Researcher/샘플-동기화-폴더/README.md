# 리서처 동기화 폴더 샘플

이 폴더는 `03-Researcher`에서 사용할 동기화 폴더의 샘플입니다.
Obsidian 볼트와 GitHub 저장소(`Vokim2503/vokim-LLMWiki260914`) 간에 동기화됩니다.

## 폴더 구조

```
03-Researcher/
├── 샘플-동기화-폴더/        ← 이 폴더 (샘플)
│   ├── README.md            ← 폴더 설명
│   └── 01-수집/             ← 리서치 자료 수집
└── (새 리서치 주제마다 폴더 추가)
```

## 사용 방법

1. 새 리서치 주제가 생기면 이 샘플 폴더를 복사해 주제 이름으로 바꿉니다.
2. `01-수집/`에 자료·링크·메모를 모읍니다.
3. 정리한 결과는 폴더 최상위에 `정리.md` 등으로 작성합니다.

## 규칙

- 파일명은 한글·영문 모두 가능하며, 띄어쓰기 대신 `-`를 사용합니다.
- 노트 간 연결은 위키링크 `[[노트 이름]]`을 사용합니다.
- 작성 후 git 커밋·푸시하면 자동 동기화됩니다.
