# 볼트 리서치 교차검토 글쓰기

글을 쓸 때 **03-Researcher의 리서치 자료를 먼저 참조**하고, 그 자료와 대조한
**비교검토**를 글과 함께 제시하여 **02-Writing/준비 폴더**에 저장합니다.
사용자가 검토를 끝낼 때까지 그 폴더에 보관합니다.

이 스킬은 글의 품질을 "리서치에 근거한 글"로 끌어올리는 것이 목적이며,
사용자 고유의 문체를 바꾸는 것은 목적이 아닙니다.

## When to Use

- 글봇에게 글(에세이·주저리·기고문·칼럼)을 써 달라는 요청을 받았을 때
- "이 주제로 써줘", "비교해서 써줘", "철인을 인용해서 써줘" 같은 요청
- 기존 초안을 리서치 자료와 대조해 검토할 때

**Don't use for:** 일기(→ `02-Writing/일기장/`, 저장 규칙 별도),
단순 맞춤법·문장 다듬기(리서치 불필요), 리서치 자체 수행(→ 03-Researcher 작성).

## Prerequisites

- 볼트 경로(읽기·쓰기): `/opt/data/obsidian-sync/vokimLLM-Wiki260914`
- **대안 볼트 경로(리서치 전용, 쓰기 가능):** `/opt/data/workspace/vokimLLM-Wiki260914`
  — vault의 `03-Researcher/` 가 root 소유라 비어 있을 수 있습니다. 리서치 검색은 **두 경로를 모두** 확인합니다.
- 리서치 자료: `03-Researcher/` (예: `철인-리서치/`)
- 글쓰기 참조: `02-Writing/철인/` (철인-리스트, 개념-계보, 보수-진보-비교)
- 준비 폴더: `02-Writing/준비/`
- 볼트 운영 지침: `03-Researcher/철인-리서치/볼트-운영-지침.md` (Skill.md 정본)

## Procedure

1. **주제와 글 종류 확인** — 무엇을, 어떤 문체로 쓸지 사용자에게 확인합니다.
   완료 기준: 주제 한 문장 + 글 종류(에세이/주저리/기고) 확정.

2. **리서치 자료 검색** — `search_files`로 `03-Researcher/`에서 관련 자료를 찾습니다.
   **두 볼트 경로를 순서대로 확인합니다:**
   - 1순위: `/opt/data/obsidian-sync/vokimLLM-Wiki260914/03-Researcher/`
   - 2순위: `/opt/data/workspace/vokimLLM-Wiki260914/03-Researcher/` (root 소유 문제로 비어 있을 때)
   - 그 밖에 `02-Writing/철인/`의 참조 자료(철인-리스트·개념-계보·보수-진보-비교)도 함께 확인합니다.
   - 완료 기준: 인용할 자료를 **1개 이상** 확보.
   - **두 경로 모두 비어 있을 때만** 글머리에 `리서치 자료 없음`을 명시하고, 확보한 참조 자료로 비교검토를 진행합니다(지어내지 않습니다).

3. **비교검토 작성** — 자료와 글의 주장을 4항목으로 대조합니다.
   - **일치** — 리서치가 뒷받침하는 지점
   - **긴장** — 자료와 어긋나거나 반대되는 지점
   - **보완** — 리서치가 더해주는 새로운 관점
   - **출처** — 각 인용의 정확한 출처
   완료 기준: 4항목이 모두 채워지고, 각 항목에 근거 문서 이름이 붙음.

4. **준비 폴더에 저장** — `write_file`로 `02-Writing/준비/YYYY-MM-DD-제목.md`에 저장합니다.
   - 같은 이름이 있으면 `-01`, `-02` … 첫 빈 번호를 붙입니다.
   - 첫 줄: `상태: 검토대기`
   - 본문 끝: `## 출처` 항목 **필수**
   완료 기준: 파일이 저장되고 첫 줄과 출처 항목이 모두 존재.

5. **한 줄 보고** — 저장 경로만 알립니다. 예:
   `✅ 02-Writing/준비/2026-09-16-가을의-가치.md 에 저장했습니다. (검토 대기)`
   완료 기준: 사용자가 파일 위치를 알 수 있음. 글 전문을 채팅에 붙이지 않습니다.

6. **이동 금지** — 사용자가 "검토 끝" 또는 "승인"을 말하기 전까지 준비 폴더의
   파일을 다른 폴더로 옮기지 않습니다. 승인 시 원래 폴더로 옮기고 상태를 `승인`으로 바꿉니다.

## 출력 템플릿

```markdown
상태: 검토대기
작성: 글봇 / YYYY-MM-DD

# 제목

(본문 — 사용자 문체 존중, 다듬기는 최소한)

## 리서치 비교검토

| 구분 | 내용 | 근거 문서 |
|---|---|---|
| 일치 | … | 03-Researcher/철인-리서치/보수-진영.md |
| 긴장 | … | … |
| 보완 | … | … |

## 출처

- 출처: 위키백과 「에드먼드 버크」 — https://ko.wikipedia.org/wiki/에드먼드_버크
- (원문 미대조 인용은 "원문 대조 필요" 표기)

## 수정 이력

- YYYY-MM-DD 작성
```

## 규칙 (볼트 Skill.md — 최우선)

- **출처 명기 필수.** `## 출처` 없는 문서는 만들지 않습니다.
- 출처를 찾을 수 없으면 첫머리에 `> 출처: 없음`을 명기하고 사용자에게 알립니다.
- 스스로 지어낸 문장은 `창작`, 요약·구성은 `편집물`로 표기합니다.
- 원문을 대조하지 못한 인용은 `원문 대조 필요`로 표시합니다.
- 사용자 문체 존중 — 의미를 바꾸는 재작성을 하지 않습니다.

## Pitfalls

- **리서치를 지어내지 마세요.** 자료가 없으면 "리서치 자료 없음"이 정답입니다.
- **준비 폴더를 거치지 않고 바로 다른 폴더에 저장하지 마세요.** 검토가 목적입니다.
- **사용자 승인 없이 파일을 옮기지 마세요.** Skill.md 7항 위반입니다.
- 볼트의 `03-Researcher`는 서버에서 root 소유일 수 있습니다. 읽기는 가능하지만
  쓰기가 막히면 `workspace` 쪽 볼트 경로에 쓰고 사용자에게 알립니다.
