# 사용 가이드 — 글봇 · 리서처 · 페르소나

> **출처: 없음** — 볼트 내부 운영 문서 (외부 출처 없음).
> 근거: 볼트 루트 `Skill.md` · [[볼트-운영-지침]]

이 문서 한 장으로 현재 시스템 전체를 볼 수 있습니다.

## 1. 구조 (한눈에)

```
03-Researcher/                     ← 원천 (Single Source of Truth)
   └ 철인-리서치/
        ├ 01-고대-철인.md          사실·출처 원자료 (여기만 보강)
        ├ 02-중세-철인.md
        ├ 03-근대-철인.md
        ├ 보수-진영.md / 진보-진영.md
        ├ 볼트-운영-지침.md        Skill.md 정본
        └ 보강-로그.md             무엇이 언제 바뀌었나

02-Writing/철인/                   ← 파생 참조본 (원천에서 파생)
   ├ 철인-리스트.md               44인 요약표
   ├ 개념-계보.md                 개념 연결 지도
   ├ 보수-진보-비교.md            10개 논점 대조표
   ├ 보수/ · 진보/                진영별 계보
   └ 페르소나/                    ★ 봇 대신 쓰는 목소리 파일
        ├ 버크.md
        └ 콩도르세.md

02-Writing/준비/                   ← 검토 대기 초안 (승인 전 보관)
```

**규칙 한 줄:** 새 사실은 **원천(03-Researcher)에 먼저** 넣고, 파생본은 원천에서 다시 만든다.

## 2. 사용법 — 이렇게 말하면 됩니다

| 하고 싶은 것 | 이렇게 말하세요 |
|---|---|
| 글 쓰기 | "○○ 주제로 글 써서 준비 폴더에 넣어줘" |
| 철인 목소리로 | "**버크의 목소리로** 써줘" |
| 대조 글 | "**보수와 진보를 대조해서** 써줘" |
| 리서처 보강 | "리서처 보강하고 파생본 갱신해줘" (또는 자동 감지) |
| 검토 승인 | "**검토 끝**" / "**승인**" → 글봇이 원래 폴더로 옮김 |

## 3. 글봇이 자동으로 하는 일 (스킬: `vault-research-crossreview`)

글을 쓸 때 **항상** 이 순서를 따릅니다:

1. (철인 지정 시) **페르소나 파일을 읽고** 그 말투·개념·금기를 따름
2. **리서처를 검색** — vault → workspace 순
3. **`## 리서치 비교검토`** 작성 — 일치 · 긴장 · 보완 · 출처 4항목
4. **`02-Writing/준비/` 에 저장** — 첫 줄 `상태: 검토대기`
5. **한 줄 보고** — 저장 경로만 (글 전문은 채팅에 안 붙임)
6. **승인 대기** — 승인 전에는 절대 이동하지 않음

## 4. 실제 예시 (실행 결과)

### 예시 ① 페르소나를 쓰지 않은 글
> **요청:** "보수와 진보의 관점 차이를 다룬 짧은 글을 써줘. 준비 폴더에 저장해줘."
> **결과:** `02-Writing/준비/2026-09-16-같은-단어-다른-세계.md`
> 본문 + 비교검토 4항목 + 출처. 버크 인용에 `(원문 대조 필요)` 표기.

### 예시 ② 페르소나를 쓴 글
> **요청:** "**콩도르세의 목소리로** '교육의 힘'에 대한 아주 짧은 글을 써서 준비 폴더에 저장해줘."
> **결과:** `02-Writing/준비/2026-09-16-교육의-힘.md`
> 글봇이 페르소나 파일을 읽고 **밝은 확신 · 평등한 교육 · 진보의 단계 · "그럼에도 불구하고"의 무게**를 반영했습니다. 인용 2곳은 `원전 대조 필요` 표기, 리서처(`진보-진영.md`)와 비교검토 4항목 포함.

### 예시 ③ 리서처 보강 → 파생본 갱신 (자동 감지)
> **변경:** `진보-진영.md` 에 「선두주자 검증」 표 추가, 콩도르세를 1번으로 승격
> **감지:** `research-watch.sh` 가 수정을 자동 감지
> **갱신:** `02-Writing/철인/진보/README.md` 반영
> **기록:** `03-Researcher/철인-리서치/보강-로그.md` 에 항목 추가

## 5. 봇 전략 (권고) — 많이 만들지 마세요

| 방식 | 봇 수 | 평가 |
|---|---|---|
| **페르소나 파일** | 1개 (글봇) | ✅ **권장** — 무한 확장, 수정은 파일 편집 |
| 대표 철인 봇 | 3~5개 | ⚠️ 정말 필요할 때만 |
| 철인 전원 봇 | 44개 | ❌ 비권장 |

**이유:** 봇 1개 = 게이트웨이 프로세스 1개입니다. 봇을 늘리면 서버 자원과 관리 대상이 함께 늘어납니다. 페르소나 파일은 그 비용 없이 같은 효과를 냅니다.

**필요하면 이렇게:** 정말 대화 상대로 쓰고 싶은 철인 2~3명만 봇으로 만들고(예: 버크 · 콩도르세), 나머지는 페르소나 파일로 두세요.
