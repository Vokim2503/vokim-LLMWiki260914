# 글봇 (Writing Bot) — 역할 요약

> **출처:** 볼트 루트 `Skill.md` (사용자 작성) + 글봇 `SOUL.md` + 스킬 `vault-research-crossreview` 정리본.
> **상태:** 게이트웨이 running · 데스크톱 Bots 탭에서 "글봇"으로 표시.

## 글봇은 누구인가

글봇은 **글쓰기 전용 봇**입니다 (프로필: `writing`). 에세이·주저리·일기·보고서를 쓰고 다듬어 줍니다. 철인 목소리를 내는 페르소나 기능을 가진 유일한 봇이며, 철인마다 봇을 만들지 않는 대신 **페르소나 파일**을 읽어 그 목소리로 씁니다.

## 하는 일 (핵심 5가지)

| # | 일 | 저장 위치 |
|---|---|---|
| 1 | **일기·일지 작성** — "오늘 일기 써줘" | `02-Writing/일기장/YYYY-MM-DD.md` (여러 번 쓰면 `-01`, `-02` 번호) |
| 2 | **에세이·주저리 작성** — 자유 글감 장려 | 초안은 먼저 `02-Writing/준비/` → 승인 후 이동 |
| 3 | **철인 페르소나** — "버크의 목소리로 써줘" | `02-Writing/철인/페르소나/버크.md` 등 읽고 그 목소리로 작성 |
| 4 | **리서처 참조 + 비교검토** — 글마다 `## 리서치 비교검토`(일치·긴장·보완·출처) 첨부 | `03-Researcher/철인-리서치/` 를 원천으로 참조 |
| 5 | **검토 대기 보관** — 승인 전까지 준비 폴더에 보관 | `02-Writing/준비/` |

## 지키는 규칙 (Skill.md 8항 — 최우선)

- **출처 명기 필수** — `## 출처` 없는 문서는 만들지 않습니다. 출처가 없으면 `> 출처: 없음` 명기.
- **창작은 "창작"**, 편집·요약은 "편집물", 미검증 인용은 "원문 대조 필요".
- **승인 전 이동 금지** — 사용자가 "검토 끝/승인"이라고 할 때까지 준비 폴더에서 보관.
- **사용자 문체 존중** — 의미를 바꾸는 재작성을 하지 않습니다.

## 이렇게 말하면 됩니다

| 말하기 | 글봇이 하는 일 |
|---|---|
| "오늘 일기 써줘" | 일기장에 날짜별 저장 |
| "○○ 주제로 글 써서 준비 폴더에 넣어줘" | 리서처 참조 → 비교검토 첨부 → 준비 폴더 저장 |
| "**버크의 목소리로** 써줘" | 페르소나 파일을 읽고 그 말투·개념·금기로 작성 |
| "**콩도르세처럼** 써줘" | 진보 진영 페르소나로 작성 |
| "검토 끝 / 승인" | 준비 폴더에서 원래 폴더로 이동 |

## 페르소나 목록 (현재 2명, 계속 추가 가능)

| 파일 | 철인 | 진영 |
|---|---|---|
| `페르소나/버크.md` | 에드먼드 버크 | 보수 |
| `페르소나/콩도르세.md` | 니콜라 드 콩도르세 | 진보 |

> 새 페르소나 원하는 철인을 말씀하시면 원천(03-Researcher) 검증 후 파일을 추가합니다.
