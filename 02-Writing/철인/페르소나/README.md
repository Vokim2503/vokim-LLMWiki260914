# 철인 페르소나 (Personas)

> **출처: 없음** — 볼트 내부 운영 문서 (외부 출처 없음).
> 근거: 볼트 루트 `Skill.md` · [[볼트-운영-지침]]

## 이 폴더의 용도

**봇을 여러 개 만들지 않고**, 글봇 하나가 철인의 목소리를 불러 쓰기 위한 정의 파일 모음입니다.

```
글봇 (봇 1개)
   └ 필요할 때 페르소나 파일을 읽음
        버크.md   → 보수의 목소리
        콩도르세.md → 진보의 목소리
        (앞으로 44명까지 확장 가능)
```

## 사용법

글봇에게 이렇게 말하면 됩니다:

- "**버크의 목소리로** 이 주제를 써줘"
- "**콩도르세처럼** 써줘"
- "버크와 콩도르세를 **대조해서** 써줘"

글봇이 해당 파일을 읽고 **말투·개념·금기**를 따라 씁니다.

## 왜 봇을 늘리지 않는가 (권고)

| 방식 | 봇 개수 | 평가 |
|---|---|---|
| 페르소나 파일 | 1개 | ✅ 권장 — 무한 확장, 수정은 파일 편집 한 번 |
| 대표 철인 봇 | 3~5개 | ⚠️ 필요할 때만 — 봇마다 게이트웨이 프로세스 |
| 철인 전원 봇 | 44개 | ❌ 비권장 — 서버 부담, 로스터 마비 |

**봇 1개 = 프로세스 1개**입니다. 봇을 늘리면 서버 자원을 쓰고 관리할 대상이 늘어납니다.
페르소나 파일은 그 비용 없이 같은 효과를 냅니다.

## 페르소나 목록

| 파일 | 철인 | 진영 | 짝 |
|---|---|---|---|
| `버크.md` | 에드먼드 버크 | 보수 | ↔ 콩도르세 |
| `콩도르세.md` | 니콜라 드 콩도르세 | 진보 | ↔ 버크 |

## 페르소나 파일 형식 (새로 만들 때)

```markdown
# 페르소나: <이름>

> 출처: (원천 문서 경로)
> 분류: 글쓰기용 페르소나 (파생본)

## 기본            ← 생몰·진영·대표 개념·대표작
## 목소리 (말투)   ← 문장 길이, 어조, 습관적 표현
## 자주 쓰는 개념   ← 반복 주제
## 금기            ← 이 사람이 하지 않는 말 (❌)
## 인용 가능 문장   ← 출처 필수, 미대조는 "원문 대조 필요"
## 글쓰기 지침      ← 전개 방식 4개 내외
## 이 페르소나의 한계 ← 오해하기 쉬운 지점
```

## 주의

- 페르소나는 **원천(`03-Researcher/`)에서 파생**됩니다. 새 사실은 원천에 먼저 넣습니다.
- 인용은 **출처 필수**, 원문 미대조는 `원문 대조 필요` 표기.
- 페르소나 파일에는 **출처 없는 명언을 넣지 않습니다.**
