# 진보 진영 (Progressive Tradition)

> **별도 저장** — 사용자 지시: "진보는 진보대로 별도로 저장"
> **출처:** 한국어 위키백과 「진보주의」·「계몽주의」·「근대 철학」 및 각 인물 표제어.

## 진보의 공통 원리 (6개)

1. **인간의 개선 가능성** — 인간과 사회는 교육·제도로 더 나아질 수 있다.
2. **이성과 보편 원리** — 관습에 의존하기보다 이성으로 보편적 원리를 세운다.
3. **제도 개혁** — 불평등하고 낡은 제도를 의식적으로 바꾼다.
4. **평등의 확장** — 신분·성별·계급의 장벽을 허문다.
5. **해방과 권리** — 자유는 타인의 지배에서 벗어나는 것에서 시작한다.
6. **역사의 방향** — 역사는 더 나은 상태로 나아간다(진보 신념).

## 진보의 핵심 문장 (개념 요약)

> 인간은 태어나 자유롭다. (루소) — *원문 대조 필요*

> 정의는 사회 제도의 제1덕목이다. (롤스, 《정의론》 첫 문장의 개념)

루소는 《사회계약론》에서 인간의 자연적 자유와 사회적 예속의 대비를 제기하며, 진보 사상의 출발점이 되었습니다.
