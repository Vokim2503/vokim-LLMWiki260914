# 개념 계보 — 시대를 관통하는 사유의 지도

> **용도:** "비슷하거나 이어지는 개념, 이상과 철인의 사고를 준비" (Skill.md) — 개념이 누구에게서 누구로 이어졌는지 한눈에 보는 지도입니다.
> **출처:** [[01-고대-철인]] · [[02-중세-철인]] · [[03-근대-철인]] 종합.

## 1. 존재론의 계보 — "무엇이 참으로 있는가"

```
탈레스(물) → 아낙시만드로스(아페이론) → 피타고라스(수)
   ↓
파르메니데스(존재는 불변) ──대립── 헤라클레이토스(만물유전)
   ↓                                    ↓
데모크리토스(원자)                    플라톤(이데아)
   ↓                                    ↓
                              아리스토텔레스(실체·현실)
   ↓                                    ↓
오컴(보편은 실재 아님)              아퀴나스(신앙+이성 종합)
   ↓
로크·버클리·흄 (경험·지각) → 칸트(물자체·현상) → 헤겔(절대정신)
```

**핵심 대립축:** 변화(헤라클레이토스) ↔ 불변(파르메니데스) — 이 대립이 2,500년간 반복됩니다.

## 2. 인식론의 계보 — "어떻게 아는가"

```
이성에서 출발 (합리론)          경험에서 출발 (경험론)
데카르트 → 스피노자 → 라이프니츠     로크 → 버클리 → 흄
            ↓                         ↓
            └────── 칸트 (종합) ──────┘
                       ↓
              피히테 → 셸링 → 헤겔
```

- **합리론** — 선천적 관념에서 지식이 시작된다 (데카르트·스피노자·라이프니츠·말브랑슈).
- **경험론** — 감각적 경험에서 지식이 시작된다 (로크·버클리·흄).
- **칸트** — 둘을 종합: 경험이 재료를 주고, 이성이 형식을 준다.

## 3. 윤리·실천의 계보 — "어떻게 살 것인가"

```
소크라테스(덕은 지식)
   ├→ 플라톤(영혼의 질서)
   ├→ 아리스토텔레스(중용·행복)
   ├→ 에피쿠로스(아타락시아)
   └→ 스토아(제논 → 세네카 → 에픽테토스 → 아우렐리우스)
              ↓
      칸트(정언명령·의무)  ←→  공리주의(결과)
              ↓
      키르케고르(실존적 선택) → 니체(가치 창조)
```

## 4. 신·초월의 계보

```
플라톤(이데아=선) → 플로티노스(일자 유출)
   ↓
아우구스티누스(내면의 신) → 안셀무스(증명) → 아퀴나스(종합)
   ↓
에크하르트(신비·영혼의 불꽃) → 오컴(신앙과 이성 분리)
   ↓
데카르트(신 존재 증명) → 스피노자(신=자연) → 니체(신의 죽음)
```

## 5. 시대별 사유 방식 요약

| 시대 | 지향 | 방법 | 대표 문장 |
|---|---|---|---|
| 고대 | 우주와 덕 | 이성·문답 | "너 자신을 알라" (소크라테스) |
| 중세 | 신과 구원 | 신앙+이성 | "믿기 위해 이해하라" (안셀무스) |
| 근대 | 주체와 인식 | 의심·경험 | "나는 생각한다, 고로 존재한다" (데카르트) |

## 6. 글쓰기에 쓸 수 있는 개념 짝(對)

| 짝 | 대립 내용 | 활용 |
|---|---|---|
| 만물유전 ↔ 존재불변 | 흐름 vs 영원 | 시간·변화 주제 |
| 이데아 ↔ 실체 | 이상 vs 현실 | 꿈과 현실 |
| 합리 ↔ 경험 | 이성 vs 감각 | 배움과 앎 |
| 의무 ↔ 결과 | 동기 vs 성과 | 도덕적 선택 |
| 실존 ↔ 체계 | 개인 vs 전체 | 개인의 자리 |
| 허무 ↔ 초인 | 절망 vs 극복 | 자기 극복 서사 |
