# 보수 ↔ 진보 비교 분석 — 글쓰기 준비 노트

> **용도:** 보수 진영([[보수/README|보수 진영]])과 진보 진영([[진보/README|진보 진영]])을 나란히 놓고 비교 분석하며 글을 만들기 위한 준비 노트입니다.
> **지침 근거:** Skill.md — "각 철인의 특성을 분류하여 비슷하거나 이어지는 개념, 이상과 철인의 사고를 준비"

## 1. 한눈에 보는 대조표 (10개 논점)

| 논점 | 보수 진영 | 진보 진영 | 대표 대립 |
|---|---|---|---|
| **인간 본성** | 불완전·이기적·타락 가능 | 개선 가능·이성적·선한 가능성 | 버크 ↔ 루소 |
| **변화의 방식** | 점진·유기적 성장 | 기획·전면 개혁 | 버크 ↔ 페인 |
| **이성과 전통** | 전통·관습이 축적된 지혜 | 이성이 보편 원리를 세운다 | 버크 ↔ 볼테르 |
| **평등** | 기회의 평등·자연적 위계 | 실질적 평등·신분 철폐 | 메스트르 ↔ 루소 |
| **자유** | 질서·법 안의 자유 | 지배로부터의 해방 | 오크숏 ↔ 밀 |
| **사회의 성격** | 유기체 (세대 간 동맹) | 계약 (구성원의 합의) | 버크 ↔ 홉스·루소 |
| **재산** | 축적의 결과, 존중 대상 | 사회적 기능, 재분배 가능 | 하이에크 ↔ 마르크스 |
| **개혁의 속도** | 작은 수정의 누적 | 제도의 의식적 재설계 | 버크 ↔ 콩도르세 |
| **권위와 질서** | 질서가 자유의 조건 | 권위는 정당성에서 나온다 | 메스트르 ↔ 페인 |
| **역사의 방향** | 순환·경계, 낙관은 위험 | 진보·더 나은 상태로 전진 | 커크 ↔ 헤겔 |

## 2. 진영별 핵심 개념 짝 (글쓰기용)

### 보수의 개념 사슬
```
인간의 불완전 → 완벽한 설계는 위험 → 전통의 지혜 존중
→ 점진적 개혁 → 질서 안의 자유 → 세대 간 동맹
```

### 진보의 개념 사슬
```
인간의 개선 가능성 → 이성으로 제도 설계 → 관습은 개혁 대상
→ 평등의 확장 → 해방으로서의 자유 → 역사의 전진
```

## 3. 같은 단어, 다른 뜻 (혼동 주의)

| 단어 | 보수가 쓰는 뜻 | 진보가 쓰는 뜻 |
|---|---|---|
| **자유** | 구속이 없되 질서와 도덕이 받쳐진 상태 | 타인의 지배·구조적 억압에서 벗어남 |
| **평등** | 법 앞의 평등, 기회의 평등 | 조건의 평등, 결과의 공정 |
| **개혁** | 보존을 위한 수정 | 불의를 바로잡는 재설계 |
| **전통** | 검증된 지혜의 축적 | 답습·관성, 극복 대상 |
| **이성** | 한계를 아는 이성 | 세계를 밝히는 이성 |

**글쓰기 핵심:** 같은 단어를 쓰면서 서로 다른 것을 말할 때 논쟁이 생깁니다. 글에서 이 지점을 짚으면 깊이가 생깁니다.

## 4. 대표 논쟁 구도 (역사적 실례)

| 논쟁 | 보수 측 | 진보 측 | 쟁점 |
|---|---|---|---|
| 프랑스 혁명 (1790) | 버크 | 페인·콩도르세 | 전통 개혁 vs 전면 재설계 |
| 인권의 근거 | 관습적 권리 | 자연권·보편 인권 | 권리는 어디서 오는가 |
| 민주주의 확대 | 토크빌(경계와 관찰) | 밀(확대와 해방) | 다수의 횡포 우려 vs 참여 확대 |
| 산업화와 자본 | 하이에크(자생적 질서) | 마르크스(소외·착취) | 시장 자율 vs 구조 비판 |
| 정의 | 커크(영속적 원리) | 롤스(공정한 평등) | 질서 우선 vs 공정 우선 |

## 5. 글쓰기 전개 모델 (3가지)

### 모델 A · 대칭 제시형
> "한쪽은 ~라고 본다. 다른 쪽은 ~라고 본다. 같은 사물을 두 눈이 다르게 보는 이유는 ~이다."

보수/진보를 순서대로 제시하고, 왜 갈리는지(인간관·시간관)를 밝힙니다.

### 모델 B · 변증법 전개형 (헤겔 구조)
> "정(보수) → 반(진보) → 합(제3의 지점)"

두 진영의 타당한 지점을 추출해 종합합니다. 예: 전통의 가치 + 개혁의 필요성.

### 모델 C · 1인칭 성찰형
> "나는 어느 쪽에 서 있는가. 왜 그렇게 서게 되었는가."

일기장·주저리에 어울립니다. 버크의 "편견" 개념을 자기 신념에 적용해 봅니다.

## 6. 인용 시 주의 (Skill.md 8항)

- 각 진영을 인용할 때 **출처를 함께 표기**합니다. 예: `— 에드먼드 버크, 《프랑스 혁명에 관한 성찰》(1790)`
- 원문을 대조하지 못한 문장은 **원문 대조 필요**로 표시합니다.
- 스스로 구성한 대조표·전개는 **창작(편집물)** 임을 밝힙니다. (본 문서의 대조표는 위키백과 자료를 바탕으로 한 편집물입니다.)
