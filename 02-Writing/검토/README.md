# 검토 폴더 (Review)

> **지침 근거:** `Skill.md` 7항 — "준비된 글은 별도의 준비 폴더를 만들어 검토대상으로 하고 검토가 끝나는 지시가 있을 때 까지 Keep한다."

## 운영 규칙

1. 검토가 필요한 초안은 이 폴더에 둡니다.
2. 파일명은 `[검토중]` 접두사를 붙이지 않고, 노트 안 맨 위에 상태를 적습니다:
   - `상태: 검토대기` / `상태: 검토중` / `상태: 승인`
3. **사용자가 "검토 끝" 또는 "승인" 지시를 내리기 전까지 이 폴더에서 이동하지 않습니다.**
4. 승인된 글만 원래 폴더(`02-Writing/에세이`, `주저리` 등)로 옮깁니다.
5. 검토 중 변경 이력은 각 노트 하단의 `## 수정 이력` 에 날짜와 함께 남깁니다.
