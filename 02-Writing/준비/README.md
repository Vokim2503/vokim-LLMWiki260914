# 준비 폴더 (Ready for Review)

> **출처: 없음** — 볼트 내부 운영 문서로 외부 출처가 없습니다.
> 근거: 볼트 루트 `Skill.md` 7항 (사용자 작성) — [[볼트-운영-지침]]

## 이 폴더의 역할

글봇이 **03-Researcher의 리서치 자료를 참조해 비교검토한 글**을 이곳에 올립니다.
사용자가 읽고 검토한 뒤, **"검토 끝" 또는 "승인" 지시를 내릴 때까지 이 폴더에 보관(Keep)** 합니다.

## 운영 규칙 (Skill.md 7항)

1. 글봇이 글을 쓰면 **항상 이 폴더에 먼저 저장**합니다. (다른 폴더로 바로 보내지 않습니다)
2. 각 노트는 첫머리에 상태를 적습니다:
   - `상태: 검토대기` — 검토를 기다리는 중
   - `상태: 검토중` — 사용자가 읽는 중
   - `상태: 승인` — 사용자가 승인, 원래 폴더로 이동 가능
3. **승인 지시 전에는 파일을 이동하지 않습니다.**
4. 수정 이력은 각 노트 하단 `## 수정 이력` 에 날짜와 함께 남깁니다.

## 파일명 규칙

```
YYYY-MM-DD-제목.md          ← 첫 번째
YYYY-MM-DD-제목-01.md       ← 같은 날 같은 제목이 또 오면 (Skill.md 일기장과 동일 규칙)
```
