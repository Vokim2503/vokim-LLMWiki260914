# 04-대사 — 별도 대사 구조

> **출처: 없음** — 볼트 내부 운영 문서.
> **작성: 유튜브봇 / 2026-09-16 : 16:20 (KST)**

## 역할

**어떻게 말할지** — 영상의 말하기 구조를 담은 대사 원고를 관리합니다.
글(03-글쓰기)과 **별도로** 분리된 대사 구조입니다.

## 글쓰기 vs 대사 구분 (사용자 요구)

| 구분 | 03-글쓰기 | 04-대사 |
|---|---|---|
| 질문 | 무엇을 말할까 | **어떻게 말할까** |
| 내용 | 스크립트·구성·논지 | 내레이션 원고·말투·호흡·강조 |
| 형태 | 글 문서 | 대사 줄 단위 (말하는 그대로) |

## 대사 구조 (템플릿)

```markdown
# 대사 원고: <제목>

> 작성: 유튜브봇 / YYYY-MM-DD : HH:MM (KST)

## 장면/타임라인
- 00:00~00:30 오프닝 (후킹 대사)
- 00:30~03:00 본론 (핵심 대사)
- 03:00~03:30 마무리 (행동 유도)

## 대사
[00:00] (밝은 톤) "여러분, 오늘은..."

## 말투 지시
- 톤: 진지·친근
- 속도: 보통, 핵심 문장은 천천히
- 금지: 망설이는 표현 (~것 같습니다 등)
```

## 규칙

- 대사 원고 파일명: `YYYY-MM-DD-주제-대사.md`
- 글(03-글쓰기)에서 대사로 옮길 때 **말투 지시**를 함께 작성합니다.
- 모든 대사에 출처·작성 한 줄(KST)·문서 통계 규칙 적용.
