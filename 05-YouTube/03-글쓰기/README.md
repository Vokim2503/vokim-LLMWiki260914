```
주제 확정 → 리서치(03-Researcher 참조) → 스크립트 작성 → 04-대사로 전달
```

- 머리말: `작성: 유튜브봇 / YYYY-MM-DD : HH:MM (KST)` + 끝에 `## 문서 통계` 한 줄.
- 스크립트가 확정되면 04-대사 폴더에 대사 원고를 만듭니다.
