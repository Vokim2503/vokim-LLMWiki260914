# 수익화 공부 로드맵

> **출처: 없음** — 일반적인 수익화 방법론 정리 (일반 상식 수준). 심화 내용은 각 항목마다 출처를 확인해 추가합니다.
> **표기:** 본 문서는 요약·구성물이므로 `편집물` 입니다.

## 0. 수익화의 기본 구조 (어떤 수익화든 같음)

```
가치 창출 → 트래픽(사람들이 봄) → 전환(행동함) → 수익(돈이 됨) → 유지(반복)
```

수익화는 이 5단계 중 어디가 약한지 찾고 고치는 작업입니다.
공부의 목표는 **이 5단계 각각을 이해하고, 내 콘텐츠에 적용**하는 것입니다.

## 1. 단계별 공부 목록

### 1단계 — 수익화 종류 이해하기 (1~2주)
- [ ] 수익화 모델 4종 이해: 광고 / 제품 판매 / 구독·멤버십 / 후원
- [ ] 채널별 특징 비교: 유튜브 · 블로그 · 뉴스레터 · 전자책 · 강의
- [ ] 각 모델의 **수익 구조**(누가, 언제, 얼마를 내는가) 파악
- 산출물: `01-정보/수익화-모델-비교.md`

### 2단계 — 트래픽 공부 (2~4주)
- [ ] 내 콘텐츠가 사람들에게 도달하는 원리
- [ ] 유튜브: 알고리즘·시청 지속 시간·썸네일의 역할
- [ ] 블로그·글: 검색(SEO)의 기본 원리
- [ ] 구독·멤버십: 신뢰와 유지의 원리
- 산출물: `01-정보/트래픽-공부.md`

### 3단계 — 전환 공부 (3~4주)
- [ ] "보는 사람"을 "행동하는 사람"으로 바꾸는 요소 (호출·신뢰·가격)
- [ ] 내 콘텐츠에 맞는 전환 방식 선택
- 산출물: `02-검토/전환-방식-검토.md`

### 4단계 — 실행 준비 (지속)
- [ ] 플랫폼 정책·수익 조건 확인 (예: 채널 구독자·시청 시간 조건 등)
- [ ] 필요한 도구·비용 정리
- [ ] 세금·법률 기초 (소득 신고, 저작권) — **전문가 확인 필요**
- 산출물: `03-실행/실행-체크리스트.md`

## 2. 검토 기준 (02-검토에서 쓸 체크리스트)

| 기준 | 질문 |
|---|---|
| 시간 | 주 몇 시간을 쓸 수 있는가? |
| 비용 | 초기 비용이 얼마인가? |
| 적합성 | 내가 가진 것(글·지식·영상)과 맞는가? |
| 수익 시점 | 첫 수익까지 얼마나 걸리는가? |
| 리스크 | 실패해도 잃는 것이 적은가? |

## 3. 공부 방법 (스터디봇 워크플로우 적용)

```
목표 확정 → 자료 수집(03-Researcher·웹) → 정리(카드/노트) → 복습(질문) → 학습 로그
```

매 학습 후 `03-실행/학습-로그.md`에 기록합니다.
