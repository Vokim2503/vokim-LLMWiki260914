# 매일 루틴 (Daily Routine)

> **출처: 없음** — 사용자 승인 후 작성된 루틴 문서 (2026-09-16).
> **표기:** `편집물`

## 30분 루틴 (기본)

```
10분  오늘의 주제 읽기 (01-정보의 카드·리서치 결과)
15분  리서치 또는 검토 작업 (요일에 따라)
 5분  학습 로그 기록 ([[학습-로그]])
```

## 60분 루틴 (여유 있는 날)

```
15분  오늘의 주제 읽기 + 지난 기록 복습
30분  리서치/검토/실행 작업
10분  산출물 정리 (출처 명기)
 5분  학습 로그 기록
```

## 체크리스트

- [ ] 오늘의 주제를 읽었다
- [ ] 출처 없는 내용은 `출처 없음`으로 표기했다
- [ ] 배운 점·모르는 점·다음 단계를 로그에 남겼다
- [ ] (있으면) 검토할 후보에 판정(✅/⚠️/❌)을 남겼다
