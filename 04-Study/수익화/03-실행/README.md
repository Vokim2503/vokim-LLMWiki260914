# 03-실행 (Execution)

> **출처: 없음** — 단계 안내 문서.

## 이 폴더의 용도

검토를 통과한 대상을 **실행**하는 단계입니다. 계획·체크리스트·성과 기록을 둡니다.

## 규칙

1. 실행 계획은 `실행-체크리스트.md`에 단계별로 작성합니다.
2. 매 학습·작업 후 `학습-로그.md`에 기록합니다:
   - 주제 · 배운 점 · 모르는 점 · 다음 단계
3. 성과는 숫자로 기록합니다 (예: 조회수, 구독자, 수익).
