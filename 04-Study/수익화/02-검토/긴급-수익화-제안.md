# 긴급 수익화 제안 (Urgent Monetization Proposals)

> **출처: 없음** — 본 문서는 사용자 상황(유튜브 채널 2개·글쓰기 자산·한글 공부앱 아이디어)을 바탕으로 스터디봇이 구성한 `편집물`입니다.
> **주의:** 여기의 트렌드·수치·정책은 **일반 상식 수준**이며, 실행 전 반드시 각 항목을 리서치해 출처를 확인합니다. ([[리서치-지형도]] 참조)

| 자산 | 상태 | 수익화 관점 |

| 유튜브 [[헌법 알아가기]] | 운영 중 | 교육 콘텐츠 → 광고·강의·전자책 |

> 핵심 원칙: **"앱 전체"가 아니라 "앱의 내용"을 먼저 판다.** 앱은 나중에.

## 1. 긴급 수익화 후보 5종 (출시 속도순)

### ⚡ 1순위 — 한글 공부 전자책/PDF 워크북 (국내외 겸용)
- 한글 공부앱을 만들려던 **콘텐츠(교재·문제·단계 설계)를 PDF/전자책으로 먼저 출시**
- 국내: 교보eBook·리디·밀리의 서재 / 해외: Amazon KDP (한국어 학습자 대상 영어판)
- 한류(K-pop·드라마)로 한국어 학습 수요가 글로벌 상승 중 — **출처 없음(리서치 필요)**
- 왜 긴급한가: 코딩 0줄, 기존 자료의 재구성만으로 출시 가능
- 산출물: `01-정보/전자책-발간.md` + 원고 → `02-검토/전자책-주제-검토.md`

### ⚡ 2순위 — 유튜브 수익화 조건 점검 + 멤버십
- [[헌법 알아가기]]·[[시대의 환각]] 채널의 YPP 자격(구독자·시청시간·숏츠) 확인 — **정책은 공식 문서로 대조 필요**
- 자격 미달이면: 숏츠·라이브·커뮤니티로 조건 채우기 로드맵
- 자격 충족이면: 멤버십·슈퍼챗·감사표현 활성화
- 산출물: `02-검토/유튜브-현황-진단.md`

### ⚡ 3순위 — 철학·헌법 에세이 전자책 (글 자산 활용)
- 02-Writing의 철인 글·헌법 시리즈를 한 권의 전자책으로 엮기
- 차별점: "철인 페르소나"라는 독특한 구성 — 시중에 없는 포지션
- 국내 전자책 플랫폼은 비교적 진입 장벽이 낮음 — **출처 없음(리서치 필요)**
- 산출물: `02-검토/전자책-주제-검토.md`

### 4순위 — 디지털 상품 (크몽·Gumroad)
- "철인과 함께하는 글쓰기" 등 **노하우를 템플릿·강의·코칭**으로 판매
- 국내 크몽, 해외 Gumroad — 결제 구조 단순
- 산출물: `02-검토/디지털-상품-검토.md`

### 5순위 — 뉴스레터·구독 (장기 자산)
- 글 자산을 주 1회 뉴스레터로 → 브런치 유료 구독·스레드(Substack) 후원
- 속도는 느리지만 **가장 안정적인 반복 수익** 구조
- 산출물: `01-정보/글쓰기-수익화.md`

## 2. 트렌드 요약 (일반 상식 수준 — 수치·정책은 리서치로 확정)

| 영역 | 현재 흐름 (상식 수준) | 검증 |
|---|---|---|
| 글로벌 한국어 학습 | 한류 확산으로 학습 수요 증가 추세 | 출처 없음 → 리서치 |
| 전자책·자기출판 | 플랫폼 성숙, AI 공저 등장으로 진입 장벽 하락 | 출처 없음 → 리서치 |
| 유튜브 수익화 | 숏츠·멤버십·브랜드딜 중심으로 다변화 | 정책 대조 필요 |
| 글·구독 경제 | 뉴스레터 유료화 보편화 | 출처 없음 → 리서치 |
