# 02-검토 (Review)

> **출처: 없음** — 단계 안내 문서.

## 이 폴더의 용도

수집한 정보를 바탕으로 **나에게 맞는지 검토**하는 단계입니다.
정보는 많지만 전부 실행할 수 없으므로, 기준에 따라 걸러냅니다.

## 검토 체크리스트

| 기준 | 질문 | 판정 |
|---|---|---|
| 시간 | 주 몇 시간을 쓸 수 있는가? | ✅/⚠️/❌ |
| 비용 | 초기 비용은 얼마인가? | |
| 적합성 | 내가 가진 것(글·지식·영상)과 맞는가? | |
| 수익 시점 | 첫 수익까지 걸리는 시간? | |
| 리스크 | 실패해도 잃는 것이 적은가? | |

## 규칙

1. 검토 문서는 `수익화-대상-검토.md` 하나에 후보별로 정리합니다.
2. 각 후보마다 **출처 있는 사실**과 **내 판단(주관)**을 구분해 씁니다.
3. 결론은 "선택" 또는 "보류"로 명확히 내립니다.
