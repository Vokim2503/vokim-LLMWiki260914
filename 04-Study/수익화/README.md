# 수익화 공부 (Monetization Study)

> **출처: 없음** — 사용자가 스터디봇에게 지시한 학습 주제 (2026-09-16).
> **지시 원문:** "수익화 공부를 해볼 작정이야. 수익화 폴더를 하나 만들고 그 폴더에서 수익화를 위한 정보, 검토 실행의 순서로 실행할 수 있게 준비해줘. 그러기 위해서 해야할 공부가 무엇이 있는지도 잘 살펴서 공부도 할 수 있게 해주고."
> **운영:** 이 폴더의 모든 문서는 [[볼트-운영-지침]] 8항(출처 명기)을 따릅니다.

## 진행 순서 (사용자 지시)

```
01-정보/  →  정보 수집 (플랫폼·방법·사례)
02-검토/  →  나에게 맞는지 검토 (비용·시간·적합성)
03-실행/  →  실행 계획과 기록
```

각 단계마다 **출처를 명기**하고, 검증되지 않은 내용은 `출처 없음`/`원문 대조 필요`로 표기합니다.

## 폴더 구조

```
04-Study/수익화/
├── README.md          ← 이 파일 (개요·진행 순서)
├── 01-정보/           ← 수익화 방법·플랫폼·사례 수집
├── 02-검토/           ← 후보별 검토 (비용·시간·적합성·리스크)
└── 03-실행/           ← 실행 계획·체크리스트·성과 기록
```

## 수익화 대상 후보 (스터디봇이 제시한 선택지)

| 후보 | 설명 | 필요한 공부 |
|---|---|---|
| 유튜브 채널 수익화 | 영상 콘텐츠 + 광고/멤버십 | 영상 제작, 알고리즘, 정책 |
| 글·콘텐츠 수익화 | 블로그·뉴스레터·매거진 | 글쓰기, SEO, 이메일 마케팅 |
| 디지털 제품·서비스 | 전자책·강의·멤버십 | 상품 설계, 결제/배포, 마케팅 |
| (미정) | 범용 로드맵으로 진행 | 위 전체의 기초 |
